# Muse AI 生日歌再创作 Demo

## 打开方式

双击 `index.html`，使用电脑上的 Edge 或 Chrome 打开即可。无需安装依赖、联网、启动服务或构建。

代码入口为 `index.html`，样式为 `styles.css`，页面预览逻辑为 `app.js`。

## 当前阶段

第二阶段：静态界面及页面状态预览。左侧是桌面演示导航，不属于 App 产品界面；中央是固定手机尺寸的 App，右侧说明预览边界。

已制作：
- 已有歌曲详情页，封面缩小为 260px，歌名放在下方居中，增加“评分与修改建议”入口。
- 评分仅展示“76分”，不展示总分或“总体匹配分”标签；2 条全局建议、3 条局部建议，建议列表可滚动，播放器固定在列表上方。
- 局部卡片的选中样式及波形范围示意，三个数字依次是范围起点、游标时间、范围终点。
- 共用浅蓝文字编辑弹窗，含保存与取消；支持 Escape 退出与键盘焦点循环。
- 勾选及重新生成按钮的默认置灰和可用样式。
- 参照截图的深蓝渐变生成等待画面，进入五秒后自动展示两首歌曲完成页；两页均保留再次编辑、创作新歌与灵感参考外观。不含原版切换和修改要求回看入口。

## 预览路径

1. 进入歌曲详情，点击“评分与修改建议”。
2. 点击一条局部建议的文字区域，查看时间轴选中范围与三个时间值。
3. 点击建议的修改按钮，或左侧弹窗预览入口，查看相同的文字编辑弹窗。
4. 勾选建议，查看底部按钮可用样式，点击后显示生成等待页面。
5. 等待五秒自动进入“创作完成”，查看双歌曲结果及截图中的灵感参考区；也可通过左侧导航直接预览。

## 尚未接入

当前不是第三、四阶段的完整可操作版本：
- 弹窗允许输入，但保存只关闭预览，不写回建议；取消同样关闭。
- 新增、删除、时间轴拖动、缩放、音频播放没有接通。点击对应入口会在 App 外侧说明。
- 五秒等待只模拟生成过程，不调用生成接口；等待期间切换其他页面会取消跳转，再次进入时重新计时。
- 返回页面时恢复初始静态状态，没有持久化。
- “再次编辑”“创作新歌”、收藏、转发等外围操作只展示外观。

76 分、建议文字、时间范围、风格和时长均为演示资料，未进行真实音乐分析。封面和灵感参考图片裁切自用户截图，见 assets/README.md。

## 用户查看要点

尚未执行浏览器验证、自动化测试或构建。请在电脑打开后重点查看：
- 手机界面内布局、建议滚动与底部按钮是否清楚。
- 详情、弹窗、时间轴及结果是否符合提供的截图。
- 浏览器窗口高度变化时，App 内是否可继续滚动。
- 时间轴三个时间值及“选中／勾选”的视觉区分是否明确。

真实音频素材、建议片段时间点与后续功能接入仍待下一阶段处理。
