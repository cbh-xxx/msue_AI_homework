# Muse AI 生日歌再创作 Demo

## 打开方式

双击 `index.html`，使用电脑上的 Edge 或 Chrome 打开。无需安装依赖、联网、启动服务或构建。

入口为 `index.html`，样式为 `styles.css`，建议和页面状态为 `app.js`，时间轴为 `timeline.js`。左侧演示导航和右侧说明不属于 App 界面。

## 当前阶段

第三阶段：建议与时间轴交互。真实音频尚未接入，播放器只模拟无声进度。

已实现：
- 详情页的 260px 封面和下方歌名；评分只显示“76分”。
- 初始 2 条全局、3 条局部建议；均支持新增、修改、勾选、立即删除。
- 新增直接创建空白卡片，不弹窗、不勾选；局部建议自动选中 00:00–00:05，游标在起点，暂停。
- 共用文字弹窗：保存生效，取消、Escape、浏览器返回均放弃草稿。背景不能操作。
- 空白和仅空格的内容可保存为空；取消勾选并置灰，不增加提示。重新填写后不自动勾选。
- 选中与勾选独立，修改非空文字或时间范围不改变勾选状态。
- 点击局部卡片非按钮区域：选中并模拟片段播放，到终点暂停。
- 拖动白色游标或点击波形自由定位，可以超出选中范围；暂停时定位不自动播放，播放时定位后继续自由播放。
- 拖动高亮两端调整范围，暂停播放，松手保存。不同建议允许重叠；范围不能超出歌曲、不能反转，最短一秒。不支持整段平移。
- 放大、缩小时间轴；放大后用下方滑条平移视窗，不修改时间范围。
- 删除当前选中的局部建议后，清除高亮、暂停，保留游标位置，不自动选中其他建议。
- 当前会话保留编辑与勾选；刷新页面重置。没有有效勾选时重新生成按钮置灰。
- 重新生成时保存所选内容和范围的快照，五秒后展示固定双歌曲结果。切换页面清除旧计时。

## 推荐演示路径

1. 点击“评分与修改建议”。
2. 点击一条局部建议，观察三个时间数字与游标进度；点击暂停。
3. 拖动两端调整范围；放大并用下方滑条平移视窗。拖动顶部游标定位到范围以外。
4. 点击修改，改写文字并保存，再勾选采纳。
5. 新增一条局部建议，确认初始为空、自动选中且未勾选；填写文字、调整范围后自行勾选。
6. 任选一条全局建议一起勾选，点击重新生成，五秒后进入结果页。

## 键盘操作

- Tab 聚焦局部卡片后，Enter 或空格选中并模拟片段播放。
- Tab 聚焦范围手柄或游标后，方向键调整一秒，Shift 配合调整五秒；Home / End 移到允许的边界。
- 编辑弹窗支持 Tab 焦点循环、Escape 取消；浏览器返回按取消处理。

## 用户检查清单

本次未运行浏览器验证、自动化测试或构建。请直接打开页面检查：

1. 修改一条已勾选建议，保存后文字更新，勾选保持；取消或浏览器返回不保存。
2. 将已勾选建议保存为空白，勾选自动清除并置灰；重新填写后恢复可选，但不自动勾选。
3. 新增两类建议，确认都是空白且不弹窗；新增局部建议高亮 00:00–00:05，游标在起点，不自动播放或勾选。
4. 一条局部建议选中时，可以独立勾选其他建议，时间轴仍只显示选中项范围。
5. 调整两端并松手，卡片时间更新；勾选状态不变；允许两条建议范围重叠，边界不越过 00:00 或 03:41。
6. 点击局部建议，模拟进度到终点停止；重新点该卡片从起点播放。拖动游标后不再受片段终点限制。
7. 放大与平移视窗时，歌曲中的范围仍对应同一秒数，不跟随画面移动。
8. 删除当前选中项，清除高亮并暂停，游标保留；删除全部建议后新增入口仍可使用。
9. 保存含换行或 `<文本>` 的内容，作为纯文字显示。切换页面再回来，文字、范围和勾选保留；刷新则重置。
10. 勾选有效建议后生成，五秒后进入结果页；等待中切走不被旧计时器拉回。

## 模拟边界

76 分、歌词建议、范围、风格及 03:41 时长均为演示资料，未对真实歌曲进行评价。SVG 波形不来自音频，无声进度也不是实际试听。真实音频素材及片段对应关系留第四阶段确定。

生成结果固定，不随编辑内容动态合成，也未连接真实 AI 或音乐接口。不增加原版对比或修改要求回看。“再次编辑”“创作新歌”、收藏和转发等外围入口只展示外观。图片来源见 `assets/README.md`。
